# Assessment and learning-content review — 2026-11-03

New content is original interview-style practice, not copied employer questions or asserted past interview questions. Difficulty is an editorial estimate, not calibrated from candidate performance. Do not describe this bank as comprehensive or predictive of interview success.

80 MCQs: 20 each in DBMS, OS, Networks and OOP. Every row has four distinct options, one correct option, a subject/topic, difficulty and an explanation. The server shuffles question/option order, balances mixed mocks, withholds keys until submission and grades stored snapshots. Structural, option-mapping, quota, ownership and grading tests run automatically. Human/external pedagogical validation remains useful; these are not psychometrically calibrated assessments.

SQL: 20 original exercises using a deterministic PostgreSQL fixture. Tests execute all solutions and compare exact row values and ordering, covering joins/anti-joins, NULLs, aggregation, HAVING, ranking, windows, conditional aggregates and self joins. No production execution of arbitrary user SQL. The scratchpad is deliberately labelled non-executing; checklist completion is self-reported.

LLD: 12 original lessons with concrete challenges and solution/tradeoff walkthroughs, including parking lot, elevator controller and expense splitting. Linked pattern articles were opened successfully during review. The supplied YouTube playlist resolves with title 'System Design Playlist'; it is linked as system design rather than mislabelled as a verified LLD course. Individual playlist videos/playback are not claimed tested. The LLD page is public and Free; signed-in users can save progress.

Code365 was reviewed as product context, not as a source to copy content or evidence for employer attribution. Existing ZIP originals and unpublished legacy packs remain preserved. No existing Core CS content import was performed. Behavioural attribution, missing interview answers, A2Z semantic checks and unresolved aptitude diagrams remain independent unfinished content work; this checkpoint does not silently mark them complete.
